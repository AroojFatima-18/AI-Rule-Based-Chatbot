# AI Chatbot

## Project Overview

AI Chatbot is a Python-based Rule-Based Conversational Agent developed as part of the DecodeLabs Artificial Intelligence Internship Program. The project demonstrates the core concepts of rule-based AI by simulating human conversation through conditional logic, predefined responses, and intelligent input processing. Instead of relying on Machine Learning models or external AI services, the chatbot makes decisions using structured programming techniques, highlighting the fundamentals of artificial intelligence and control flow.

## Key Features

* Rule-based conversational chatbot built entirely in Python.
* Interactive command-line interface with a clean and user-friendly design.
* Supports greetings, small talk, AI-related questions, and general chatbot interactions.
* Displays the current date, time, and day using dynamic responses.
* Smart input normalization for consistent recognition of user queries.
* Keyword-based matching for improved response accuracy.
* Intelligent command suggestions for unrecognized inputs.
* Built-in **Help** menu for supported commands.
* **Clear** command to refresh the console.
* Multiple exit commands such as **bye**, **exit**, and **quit**.
* Smooth typing animation for a more natural conversational experience.
* Modular, readable, and well-documented code following clean Python programming practices.

## Technologies Used

* Python 3
* Standard Python Libraries:

  * datetime
  * time
  * os
  * re
  * sys
  * difflib

## How to Run

1. Ensure Python 3 is installed on your system.
2. Download or clone the project files.
3. Open a terminal or command prompt inside the project directory.
4. Execute the following command:

```bash
python chatbot.py
```

5. Start interacting with the chatbot through the terminal.
6. Type **help** to view the available commands.
7. Type **bye**, **exit**, or **quit** to close the chatbot.
